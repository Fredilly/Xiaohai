The public Caddy accepts `staging-api.pamboo.asia` and any independently existing domains, plus `api.pamboo.asia`, `store.pamboo.asia` and `admin.pamboo.asia` after cutover. The production API service is deliberately named `production_api` with edge alias `production-api`, **not** `api`, to avoid colliding with Staging's existing Docker DNS alias `api` on the shared proxy. Internal web serves on container port 8080 without a host publication.
