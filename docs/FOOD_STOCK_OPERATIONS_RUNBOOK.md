# #208 食品入库与状态管理（尚未上线）

仅限预包装食品、瓶装饮料；现制配方不自动扣料。共享商品资料、门店独立售价。

## 代码与环境边界

0044 在 0042/0043 后增加可空食品分类及 NEW_LOT_RECEIPT 账本类型。历史 NULL 分类继续不可售，不自动伪造来源。不能覆盖旧迁移或在已应用旧食品 0041 的环境跳过冲突。

`FOOD_STOCK_WRITES_ENABLED=false` 是默认配置；仅明确字符串 true 开启写接口。部署/迁移/开启配置均须独立环境授权。本轮只运行自主创建的临时 PostgreSQL，没有共享环境变更。

## 迁移前后

负责人核验环境身份、完整备份及实际恢复演练、既有 migration journal/hash，安排停止旧食品写入的窗口。先在独立恢复副本执行仓库标准迁移并核对商品/门店库存数量和账本总量。正式操作另行授权；遇到旧食品 0041、孤儿或余额不符即 STOP。

0044 不回填食品来源、不调整任何库存。只读核验字段、约束、函数、journal 与分类 NULL 数量；既有库存和账本总量必须不变。恢复使用已验证备份；应用回滚须继续关闭食品写入及下单，不能移除账本约束或直接删迁移记录。

## 流程

门店或总部先建立非图书商品草稿并关联本店零库存；首次分类还要求 catalog.edit、没有销售/租借/库存历史且只关联本店。通过正式 intake 录入批号、种类、日期、数量、内部凭证编号，入库默认 HELD。服务端根据门店时区检查日期，事务内同时创建总流水、批次流水、库存及审计。

库存界面选择门店和 SKU，读取真实批次；检查后 AVAILABLE、冻结 HELD、召回 RECALLED 均有版本、幂等、服务端范围和审计。释放拒绝过期、未验证分类或总账不符。多批次报损/盘亏沿用 #217 原子 writer，当前只支持未冻结、未过期且有可用余量的批次；0045 新增显式 DISPOSAL：只接受冻结/召回或过期批次，保留原状态，生成 ADJUSTMENT_OUT 总流水及 DISPOSAL 批次流水。禁止消耗 reserved 或显式 blocked 计数；相关分配须由其归属流程解除，不能先释放或改日期绕过。普通报损仍拒绝过期/冻结批次。

## 尚未完成的经营门槛

食品 FEFO 预留、销售履约、退款返库和跨店调拨尚未闭环。已识别食品 SKU 在普通库存、租借、公共商品可购和订单预留/扣减路径拒绝处理，响应 checkoutEnabled=false。不可将物理批次可售量当作可下单授权。

真实门店 Excel/盘点来源、浏览器交互、WeChat 真机、共享环境迁移和实际经营均未验收；CI、SSR、临时数据库不能替代这些验收。

0045 是只扩展类型/负向方向检查及总流水身份映射的前向迁移，不修改既有数量或流水。沿用上述备份/恢复与停写门禁；禁止回滚成不认识 DISPOSAL 的写入进程。

## 0046：FEFO 批次预留与释放基础（仍不可下单）

0046 仅新增 `food_batch_reservations` 与不可变 `food_batch_reservation_events`，通过复合 Store/SKU/批次外键、同订单项同批次唯一约束、状态单向转换、提交时延迟事件完整性检查，保存 RESERVE / RELEASE 证据。它**不**调整历史库存或自动把现有订单转为批次订单。内部 `FoodReservationService` 先锁订单，再锁门店 SKU 总库存和全部批次，复核真实批次总量、现有未释放分配和门店本地日期，只在已发布、类型核验、未冻结、未过期的批次上按最早到期日和稳定批次 ID 分配。释放保留原批次身份，即使批次后来召回也可解除预留，绝不将召回库存自动恢复可售。纯领域回归覆盖排序、冻结和不足；真实并发和事务回滚须通过专属一次性 PostgreSQL 测试复验，未跑到时明确标为 NOT VERIFIED。

**关键边界：** 预留/释放仍为内部基础设施，不接入小程序 checkout、订单取消或履约按钮，不开放路由；`checkoutEnabled=false` 和食品写入默认关闭。销售扣减、退款返库、食品调拨与其完整状态机未完成前不得更改这两个门禁。普通订单不可复用 0046 表来绕过食品限制。

应用前同样须由数据库负责人确认精确目标、可恢复备份及恢复演练、0042–0045 已正确应用、停写窗口与可用的回滚路径。在专属恢复副本核对 0046 SQL 和迁移 journal、空表初态、库存和销售流水基线；只在测试数据库验证并发预留 5 件竞争、跨店拒绝、过期拒绝、幂等释放以及伪造事件提交回滚。生产或共享环境应用必须另获明确授权；失败时保持写入/下单关闭，保留数据库快照与错误证据，使用经验证的恢复流程恢复整个目标环境，不手工删 0046 表、篡改流水或编辑迁移 journal。
