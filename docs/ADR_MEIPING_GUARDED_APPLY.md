# ADR: 美萍审核结果的受保护导入

状态：Draft，等待业务方确认最终导入授权规则。

## 决策

美萍审核会话与正式导入分离。服务端从持久化审核快照生成 Dry Run 批次，校验门店、源文件 checksum、每行最终审核决定及当前纠错版本。`ACCEPTED` 纠错只代表该版本可以进入导入计划，不代表整批获准导入。

导入批次必须由不同于创建预览的 Staff 身份独立批准。批准后如果审核决定或纠错版本变化，旧批准失效，必须重新预览和批准。批次、逐行结果、库存流水和审计记录使用同一 PostgreSQL 事务；批次 checksum/idempotency 及库存流水唯一键阻止重复写入。

正式执行由 `MEIPING_IMPORT_EXECUTION_ENABLED` 控制，默认关闭。只有隔离 UAT 或经过明确生产发布批准的环境才允许开启。新书默认 `DRAFT`、不可售；库存数量只能来自审核时填写的实际盘点数量，0 不生成虚假的零增量流水，正数生成 `INITIAL_MIGRATION` 流水。

## 范围

只处理图书主数据、SKU 和当前门店库存；不导入会员、订单、财务、历史租借、供应商或佣金。匹配不确定、缺少正式图书必填主数据、已有非零库存或数据冲突时整批回滚并要求人工处理。

## 未决事项

正式环境最终批准人的组织职责、是否允许执行开关在生产开启、以及缺失作者等资料的最终补齐流程仍需业务方确认。未确认前不得使用真实美萍文件执行正式导入。
