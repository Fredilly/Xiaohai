# #208 独立门店售价：迁移、回退和验收

## 业务与实际变更

2026-11-24 用户确认「共享商品资料、门店独立售价」。`0043_store_sku_independent_prices`
为 `store_catalog_metadata` 增加整数分 `store_price_minor` 和非负约束，并将每个既有
库存关联的当前 SKU 参考价快照为本店价。新建库存关联时由事务内触发器初始化本店价。
后续 HQ SKU 参考价修改不会传播到已初始化的本店价。

新增复合 FK 使本地资料只能属于真实 `store_inventory(store_id,sku_id)`。
删除库存关联时只级联其本地资料，不删除任何库存或审计流水；业务 API 没有新增删除库存功能。
存在历史孤立本地资料时迁移应失败，先在备份副本核对并准备人工审核的修复，禁止自动丢弃。

门店和 HQ 指定门店编辑复用 `CatalogEditService`，售价按 localVersion 锁定、审计，
不再修改全局 SKU 价格/版本或要求跨店影响 token。共享名称/ISBN 等仍保留原权限和签名影响确认。
门店价、货架等编辑按既有 Store 数据范围保护。总部商品主档显示的 SKU 参考价与门店价明确区分。

## 结算一致性

- 店内找书结果显示本店价；商城和未选店购物车显示参考价说明。
- 自提/配送报价按所选门店价计算。缺少本店价记录时拒绝报价，不静默使用总部价。
- 下单事务先取得消费者购物车锁和对应库存锁，再锁定本地价格和商品/SKU，重新计价并保存成交快照。
- 客户端传确认总额用于拒绝过期报价，不能指定实际收费。服务器始终自行计算。
- 购物车增减/删除共用消费者锁，不能在结算中途替换已预留的数量。
- 旧的无门店结算入口对已关联门店的 SKU 失败即停止，不能绕过所选门店价。
- 商品的旧签名/私有封面链接不再直接进入公开商品响应；写入也拒绝非稳定公开 HTTPS 封面。

## 测试和共享环境门禁

只在新建、独占的临时 PostgreSQL 集群和 allowlist 测试库执行仓库标准迁移。
`store-independent-price.integration.test.ts` 使用本进程新建并迁移的 UUID 子库，
覆盖独立定价、全局价不传播、所选门店报价和订单快照、过期报价回滚、并发改价、缺失价格、
旧入口拒绝和公开封面脱敏。测试用例不执行真实支付。

共享/Staging/生产的 0043 包含价格快照回填，必须先完成独立安全审查、最新 CI、
精确版本/journal/hash 核对、库身份、写入窗口、备份及实际恢复演练，以及明确的环境操作授权。
本轮没有执行这些环境的迁移，也未部署。`STAGING_READY=false` 保持不变。

应用前核对关联、孤立 metadata、SKU/本地价格分布、版本及审计数量；应用后逐店对账，
确认价格初始化不改变数量、预留、库存流水或历史订单金额。并发写入须停止或处于已审核的锁窗口。

## 回退

不能将旧应用直接回退到忽略本店价的版本后继续收单，否则会按错误参考价收费。
先停止新报价/下单，保留本店价和所有历史订单/审计，再按独立审核的兼容修复恢复。
不自动 DROP 列、不覆盖门店价、不重写库存或订单、不重置迁移历史。

## 未替代的门禁

食品批次结算、真实 BOS 图片域名及授权、门店/总部浏览器交互、微信 iOS/Android 真机、
实际库存建档与迁移验收仍要各自完成；不得以独立售价的 PostgreSQL 测试代替这些结果。
